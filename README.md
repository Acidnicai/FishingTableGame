# 工位

悬浮在桌面上的小窗口。上班的时候可以看日历、钓一会儿鱼、种一块地、跑一只恐龙，或者拆一包卡。

窗口没有边框，会跟着系统的浅色或深色主题。可以拖动，可以钉在别的窗口上面，也可以收成一枚小钟。

## 开始

双击 `启动小鱼塘.bat`。

第一次打开会自己配置环境：电脑上有 Node.js 就直接用，没有就下载一份便携版，然后安装依赖。这一步需要联网。完成之后，再双击就会直接进入。

已经装了 Node.js 的话，也可以：

```bash
npm install
npm start
```

## 里面有什么

金币是共用的。新的一局从 **400 金**开始，这个季节会送几颗种子。

- **日历 / 本周**：记一句今天的事，排这一周的事。默认按 09:00–18:00 算下班倒计时，可以自己改。
- **鱼塘**：五个地方，每个地方 50 种鱼，另外还会钓到草鞋、瓶子这类杂物。图鉴里是实拍，点开能看到分布和照片署名。
- **耕地**：锄、浇、收、铲。浇过水之后，大约 40 分钟成熟。收成可以卖掉。
- **恐龙**：路上的金币捡到就入账，撞上之后按分数再结一笔。
- **卡牌**：第一弹「退潮」，一包五张，80 金。每张单独算，没有保底。

卖掉钓到的鱼和收成的菜，就能得到金币。金币用来买种子、解锁地图、拆卡包。

### 地图

开局只有蓝洞。其余地图点一下就能买，金子不够会告诉你还差多少。越后面的地方，鱼越容易卖得更贵。

| 地图 | 解锁 |
| --- | --- |
| 蓝洞 | 一开始就开 |
| 深海 | 800 金 |
| 洞穴 | 1800 金 |
| 浅海 | 3600 金 |
| 江河 | 7200 金 |

### 操作

鱼塘里点水面，或者按抛竿。咬钩时提竿。空格是当前这一下的主动作。

耕地：

- `1` 锄，`2` 壶，`3` 收，`4` 铲
- 空格对脚下使用，`R` 对整块田使用
- `Q` / `E` 换种子，`B` 打开背包
- `WASD` 移动，`Shift+W` 放大，`Shift+S` 缩小，滚轮也可以缩放

恐龙里空格、回车或上键跳，下键低头。

## 存档

进度写在本机，不上传。Windows 上是：

`%APPDATA%\小鱼塘\pond.json`

里面有金币、鱼册、菜地、卡牌和窗口位置。删掉这个文件就会回到新的一局。
